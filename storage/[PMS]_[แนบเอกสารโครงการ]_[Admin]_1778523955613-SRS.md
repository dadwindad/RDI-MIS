Software Requirements Specification (SRS)
Project Name: Mudmee Symmetry & 3D Studio (File-based Edition)

Version: 2.1

Status: Final Draft

1. Purpose & Scope (วัตถุประสงค์และขอบเขต)
แอปพลิเคชันนี้มีวัตถุประสงค์เพื่อเป็นเครื่องมือออกแบบลายผ้ามัดหมี่เชิงลึก โดยใช้หลักการคณิตศาสตร์สมมาตร (Symmetry Groups) เพื่อสร้างแม่ลาย (Motif) และการประกอบผืนผ้า (Fabric Assembly) ที่มีความแม่นยำทางศิลปะและเทคนิค พร้อมระบบจำลอง 3 มิติในลักษณะการนุ่งผ้าถุงจริง โดยข้อมูลทั้งหมดจะถูกจัดเก็บในรูปแบบไฟล์ดิจิทัลบนอุปกรณ์ของผู้ใช้ เพื่อความเป็นส่วนตัวสูงสุด

2. Functional Requirements (ข้อกำหนดด้านฟังก์ชัน)
FR1: Motif Design System (ระบบออกแบบแม่ลาย)
Symmetry Engines:

ตัวผ้า (Body): รองรับ Wallpaper Groups (p3, p31m, p3m1) สำหรับการซ้ำแบบเต็มระนาบ

ตีนผ้า (Border): รองรับ Frieze Groups ครบทั้ง 7 รูปแบบ (เช่น p111, p1m1, pmm2)

Drawing Tools:

Real-time Symmetry: วาดหนึ่งจุด ระบบกระจายจุดสมมาตรโดยรอบตามกฎเรขาคณิตทันที

Visual Aids: ระบบเส้นกริต (Grid) และเส้นแกนสมมาตร (Axes) ที่ปรับขนาดได้ (40px - 200px)

Tracing Image Overlay: สามารถอัปโหลดภาพถ่ายจากอุปกรณ์เพื่อวางซ้อนจางๆ (Opacity 30%) เป็นต้นแบบการวาด

FR2: Color & Metadata Management (การจัดการสีและข้อมูล)
3-Color Palette: จำกัดสีหลัก 3 สี เพื่อให้สอดคล้องกับข้อจำกัดทางเทคนิคของการมัดย้อมจริง

Metadata Entry: บันทึกข้อมูลประกอบด้วย ชื่อลาย, ชื่อผู้สร้าง, คำอธิบาย และพื้นที่ภูมิศาสตร์

FR3: Fabric Assembly & Resizing (ระบบประกอบผืนผ้า)
Modular Stitching: นำส่วนตีนผ้าและตัวผ้ามาต่อกันเป็นผืนเดียว (Joint Layout)

Interactive Scaling: ใช้เมาส์หรือการสัมผัสลากปรับ "ความสูง" ของแต่ละส่วนได้

Tiling Logic: เมื่อขยายพื้นที่ ลายผ้าจะทำการวนซ้ำ (Repeat) โดยอัตโนมัติ แทนการยืดภาพ (No Distortion) เพื่อรักษามาตราส่วนลายที่ถูกต้อง

FR4: 3D Visualization (การจำลอง 3 มิติ)
Pha Thung Mannequin: แสดงหุ่นจำลองเฉพาะส่วนล่าง (เอวถึงเท้า)

Lower-body Wrapping: นำภาพลายผ้าที่ออกแบบมาหุ้มโมเดลในลักษณะ "ผ้าถุง" หรือทรงกระบอกสอบ

360° Interaction: ผู้ใช้สามารถหมุนและซูมหุ่นดูได้ทุกทิศทาง

FR5: File-based Data Storage (การจัดเก็บข้อมูลแบบไฟล์)
Project Export (JSON): ส่งออกโครงสร้างลายผ้า (พิกัดจุด, สี, มาตราส่วน, และชื่อลาย) เป็นไฟล์ .json เพื่อเก็บไว้แก้ไขต่อในภายหลัง

Fabric Export (PNG): เรนเดอร์ผืนผ้าที่ต่อลายสมบูรณ์แล้วเป็นไฟล์ภาพความละเอียดสูง เพื่อนำไปใช้สั่งงานทอหรือนำเสนอ

Project Import: รองรับการโหลดไฟล์โครงสร้างลาย (.json) กลับเข้าสู่แอปพลิเคชัน

3. Technical Specifications (ข้อกำหนดทางเทคนิค)
Platform: Web-based SPA (Single Page Application) รองรับ Responsive บน PC และ Smartphone

Frontend Stack: HTML5, Tailwind CSS, JavaScript (Vanilla/ES6)

Graphics Engines:

2D: HTML5 Canvas (Matrix Transformation Processing)

3D: Three.js (WebGL Rendering)

Storage Strategy: Client-side Storage (Blob API / File System Access API) ไม่มีการใช้ Backend Database เพื่อลดความเสี่ยงด้านข้อมูลส่วนบุคคล

4. User Interface (UI) Design (ข้อกำหนดด้าน UI)
Workspace: แบ่งพื้นที่เป็น 3 โหมดชัดเจน: Design (วาด), Assemble (ประกอบ), และ Preview (3D)

Configuration Panel: แถบควบคุมด้านข้าง (Sidebar) สำหรับปรับแต่งสี, ขนาดกริต และประเภทสมมาตร

Theme: ใช้โทนสีอบอุ่น (Stone-50) ร่วมกับสีแดงครั่ง (Rose-600) เพื่อสื่อถึงงานหัตถกรรมไทย

5. Non-Functional Requirements (ข้อกำหนดด้านประสิทธิภาพ)
Offline Availability: แอปพลิเคชันต้องทำงานได้โดยไม่ต้องใช้อินเทอร์เน็ตหลังจากโหลดหน้าเว็บครั้งแรก

Latency: การคำนวณสมมาตรใน Canvas ต้องมีการตอบสนองภายใน 100ms เพื่อความลื่นไหลขณะวาด

Scalability: ข้อมูลโครงสร้างลายในไฟล์ JSON ต้องมีขนาดกะทัดรัด (ปกติ < 1MB) เพื่อความสะดวกในการรับ-ส่งไฟล์
